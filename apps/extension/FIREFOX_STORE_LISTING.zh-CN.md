# Firefox Add-ons listing: Simplified Chinese

Translation of the description in [FIREFOX_STORE_LISTING.md](FIREFOX_STORE_LISTING.md).

RTNote 网页剪藏插件可将当前网页、选中的文字、右键选中的图片、X 上的一条推文、Reddit 上的一条帖子、其他受支持社交网站上的一条帖子，或 GitHub 仓库的地址和简介直接保存到用户配置的自托管 RTNote 实例。

- 提取适合阅读的文章正文。选中文字后右键，只保存这一段。
- 在图片上右键，把图片文件存成一条新笔记。从 Google 搜索保存时，笔记记录“Google 搜索”和关键词。
- 在 X 上右键推文正文。长文会先展开“显示更多”，再保存全文和已经显示的图片。
- 在 Reddit 帖子正文上右键，保存标题、作者、社区、正文、链接和图片，不写入评论。
- 在 Hacker News 主帖详情页保存标题、作者、原始时间、剪藏时的分数、外部链接和主帖正文，不写入评论。
- 在 Facebook、Instagram、LinkedIn、Threads 和 Bluesky 上右键帖子，保存正文和图片。
- 可以把 YouTube 播放页保存为带时间戳字幕的视频笔记。
- 这些命令直接出现在右键菜单的第一级。
- 在浏览器本地将 HTML 转换为 Markdown。
- 可选择默认 RTNote 笔记本。
- 数据直接发送到用户自己的实例，不经过 RTNote 中转服务。
- 不包含广告、分析、追踪或遥测。

使用前，请在插件设置中填写 RTNote 实例地址和 API Token。插件只会在用户选择剪藏或保存命令（包括“保存 Reddit 帖子到 RTNote”）后读取并发送网页内容。
